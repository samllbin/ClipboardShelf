# 拾光剪贴板 ClipboardShelf

轻量的原生 macOS 剪贴板历史工具，像输入法候选框一样选择要粘贴的内容。

**短按 ⌘V 粘贴当前内容；同时按住 ⌘ 和 V 约 0.4 秒打开历史，用 ↑ / ↓ 选择，回车粘贴。** 日常操作只用一个小候选框，历史管理和外观设置按需打开。

当前版本 **1.3.0** · macOS **13+** · Swift / AppKit / SwiftUI · 无第三方运行时依赖

## 功能

- **轻量候选框**：约 340 × 330，优先出现在输入光标旁，无法获取光标位置时显示在鼠标附近。
- **图片预览**：图片记录直接显示真实缩略图；点击放大镜或按空格展开大图，确认内容后再粘贴。
- **剪贴历史**：记录文本、链接、富文本、图片和文件引用，尽量保留原始剪贴板格式；历史自动保存，重启后可继续使用。
- **全部历史搜索**：最多 500 条，支持正文、来源应用、类型、文件名和路径等字段；当前可见条数不限制搜索范围。
- **保存与备份**：收藏常用内容、保存单条内容、从文件导入，以及导出 / 导入 JSON 历史备份。
- **自定义皮肤**：6 种内置配色、自定义强调色、浅色 / 深色 / 跟随系统，以及本地图片背景和浓度调整。
- **本地运行**：没有账号、云同步或剪贴板上传；支持暂停记录和清理历史。

## 安装与启动

### 使用打包应用

从 [GitHub Releases](https://github.com/samllbin/ClipboardShelf/releases/latest) 下载打包的 ZIP，解压后将「拾光剪贴板.app」放到固定位置，例如「应用程序」文件夹，再打开。应用常驻菜单栏，启动后不会自动打开大管理窗口。预编译包适用于 Apple Silicon（arm64）；Intel Mac 请从源码构建。

当前构建使用本地 **ad hoc 签名**，未包含 Developer ID 签名与公证流程。若 macOS 拦截打开，请确认来源后，使用系统「隐私与安全性」中的打开选项。

### 从源码构建

需要 Xcode 或 Xcode Command Line Tools，以及 **Swift 5.9 或更新版本**。克隆本仓库后执行：

```bash
git clone https://github.com/samllbin/ClipboardShelf.git
cd ClipboardShelf
./scripts/build-app.sh
open "dist/拾光剪贴板.app"
```

也可以执行：

```bash
./scripts/run.sh
```

`run.sh` 在应用不存在时自动构建；修改源码后需再次运行 `build-app.sh`。构建产物位于 `dist/`，构建与模块缓存位于 `.build/`，脚本不会自动安装到「应用程序」文件夹。默认构建当前 Mac 架构的应用，不是通用二进制。

### 启用长按 ⌘V

1. 打开 **系统设置 → 隐私与安全性 → 辅助功能**。
2. 添加当前的「拾光剪贴板.app」并开启权限。
3. 右键菜单栏图标，确认显示 **「长按 ⌘V：已就绪」**。
4. 回到目标应用，先按住 **⌘**，再按住 **V**，两个键保持约 **0.4 秒**。

辅助功能权限用于识别全局按键、定位输入位置和向原应用发送粘贴。应用每 2 秒检查一次授权状态，授权生效后会自动启用。未授权时，系统原来的 ⌘V 行为保持不变；仍可从菜单栏或 ⌘⇧V 打开候选框，选中记录复制后手动粘贴。

**更新或重新构建后，旧授权可能失效。** 即使辅助功能列表仍显示已开启，也可能不对应新版签名。请移除旧的「拾光剪贴板」条目，用「＋」重新添加当前版本并开启。菜单栏的「检查长按状态…」会显示版本、监听状态与当前应用路径。

## 日常使用

先运行应用，再正常复制或剪切内容，新的内容会进入历史。启动前已经在剪贴板中的内容不会自动写入历史，可通过管理窗口的「立即读取剪贴板」主动保存。

| 操作 | 行为 |
| --- | --- |
| 短按 ⌘V | 松开 V 或 ⌘ 时粘贴当前内容一次 |
| 同时按住 ⌘ 和 V 约 0.4 秒 | 打开历史候选框，出现后即可松开 |
| ↑ / ↓ | 选择上一条 / 下一条 |
| 回车或点击记录 | 确认选择并粘贴 |
| 输入关键词 | 搜索全部历史 |
| 图片行右侧放大镜 | 展开该图片的预览，不粘贴 |
| 空格（搜索框为空且选中图片） | 展开 / 收起图片预览 |
| Fn+↑ / Fn+↓ | 向前 / 向后移动 5 条 |
| 滚轮 | 浏览更多历史 |
| Esc | 先收起图片预览，再按一次关闭候选框 |
| 点击候选框外 | 关闭候选框 |
| ⌘⇧V 或左键菜单栏图标 | 直接打开候选框 |
| 右键菜单栏图标 | 查看状态、管理历史、设置皮肤、暂停或退出 |

为区分短按与长按，短按粘贴发生在松键时，不需要等满 0.4 秒。长按不会先粘贴一次，松手也不会自动确认。默认候选项为当前系统剪贴板；只唤起或取消候选框不会改写剪贴板。

候选框一次约显示 5 条，可以继续向下浏览全部记录。右上角显示当前位置与匹配总数。切换到其他应用会关闭候选框；候选期间剪贴板发生变化时，需要重新唤起再选择。

### 搜索

输入内容关键词、来源应用名称、应用标识、类型、文件名、路径或链接。空格分隔的多个词都需要匹配，可以分别命中不同字段，例如：

```text
项目 Finder 文件
```

搜索忽略英文大小写、重音符号以及全角 / 半角差异，也支持 URL 编码后的中文文件名。中文输入法的组合输入期间，候选框会将选字按键交给输入法。图片记录可按来源、类型等字段搜索，**目前没有图片文字识别（OCR）**。

### 图片先预览，再粘贴

图片记录左侧会显示实际内容的缩略图，不再只用通用图片图标。点击该行右侧的放大镜即可展开大图，也可以用 ↑↓ 选中图片后按空格。展开区域保留完整比例、显示原始像素尺寸，透明图片使用棋盘格背景。

展开时按 ↑↓ 切换到另一张图片，预览会同步更新；切换到文字记录时自动收起。按 Esc 或点击预览区的关闭按钮只收起大图，回车才粘贴所选记录。直接点击行内缩略图或文字仍沿用原来的粘贴操作；放大镜是专门的预览入口。

空格快捷键仅在搜索框为空时生效，有关键词时仍可输入空格搜索。展开后浮层通常为 340 × 510，屏幕空间不足时会缩短列表和预览区域，收起后恢复小候选框。

支持 PNG、JPEG、TIFF、HEIC/HEIF 和 GIF 首帧。缩略图在后台解码并缓存，切换记录时不会把上一张图当作当前预览；无法解码的图片会显示提示，仍可粘贴原始内容。预览仅使用已保存的图片字节，不联网读取图片或打开文件引用。

### 历史管理、保存与恢复

通过候选框右下角 **齿轮 → 管理历史记录…**，或右键菜单栏图标打开管理窗口。

- 收藏常用记录、删除单条记录、清理未收藏历史。
- 将记录复制回剪贴板，或以纯文本形式复制；「粘贴到原应用」需要辅助功能权限。
- 保存选中内容为文件，或从本地文件导入内容。
- 导出 JSON 备份，再通过导入备份合并恢复历史；重复内容会去重，已有收藏状态会保留。
- 暂停采集时仍可使用已有历史；暂停期间的复制内容不会在恢复后补录。

「清空系统剪贴板」只清空当前剪贴板，不删除已保存的历史。JSON 备份只包含历史记录，不包含皮肤设置、背景图片或文件引用指向的原文件。

| 存储限制 | 上限 |
| --- | --- |
| 历史记录 | 500 条 |
| 历史内容总量 | 200 MiB |
| 单条内容与可搜索文本合计 | 20 MiB |
| 可读取的 JSON 备份文件 | 300 MiB |

达到容量限制时优先保留收藏，再保留较新的普通记录；收藏自身超过限制时，也会保留较新的收藏。导入备份会先验证整个文件，无效格式、重复记录 ID 或超限数据会被整体拒绝。

### 自定义皮肤与图片

打开 **齿轮 → 皮肤与背景图片…**：

- 选择竹青、海盐蓝、玫瑰、琥珀、鸢尾、石墨配色，或使用颜色选择器自定义强调色。
- 切换跟随系统、浅色或深色模式。
- 导入本地 PNG、JPEG、HEIC 等受支持的图片作为背景，调整 5%–50% 的背景浓度。

外观修改即时生效，无需重启。图片输入上限为 50 MiB；应用提取第一帧，将最长边缩至不超过 2200 像素，保存为本地 PNG 副本。不会上传图片，也不会修改原文件。

## 常见问题

### 长按到底按哪个键？为什么一直在粘贴？

需要 **⌘ 和 V 两个键同时保持按下约 0.4 秒**，不是只按住 ⌘、反复点击 V。

若持续执行普通粘贴，先右键菜单栏图标查看「长按 ⌘V」状态，再打开「检查长按状态…」：

- **辅助功能授权未生效**：按上面的授权步骤重新添加当前应用，尤其是更新或重新构建之后。
- **已关闭**：选择「开启长按 ⌘V 候选栏…」。
- **系统安全输入暂时阻止拦截**：关闭密码输入等安全输入场景，或使用菜单栏入口。
- **键盘监听未启动**：确认权限后，从菜单栏退出应用，再打开当前版本。

### 更新后要重启吗？

需要从菜单栏选择 **「退出拾光」**，再打开新版应用。关闭候选框或管理窗口不会结束后台进程。无需重启电脑；更换皮肤也不需要重启应用。

### 为什么只有 5 条？

5 条是候选框一次可见的数量。继续按 ↓、滚动或翻页即可浏览更多，搜索覆盖全部已保存记录，最多 500 条。

### 文件记录可以当作文件备份吗？

不可以。文件记录保存的是引用，原文件移动、删除或设备断开后，引用可能失效。JSON 导出不会打包原文件。应用不会移动或删除原文件；Finder 移动文件仍使用 **⌘C → ⌥⌘V**。

### 如何退出或临时停用？

右键菜单栏图标可暂停记录、关闭长按候选栏或退出应用。应用退出后不再采集或响应快捷键，已保存历史仍在本机。

## 隐私与使用边界

历史和背景副本分别保存在：

```text
~/Library/Application Support/ClipboardShelf/history.json
~/Library/Application Support/ClipboardShelf/appearance/background.png
```

外观偏好保存在本机应用偏好设置中。历史与导出的 JSON 备份**未加密**；应用会跳过已识别的密码管理器和标记为私密的内容，但无法识别所有敏感文本。普通复制的密码、令牌或个人信息仍可能进入历史，可按需暂停采集并清理。

其他限制：

- 剪贴板约每 0.6 秒检查一次，快速连续复制可能只能捕获部分版本。
- 仅保存实际可读取的格式；应用按需提供的临时数据、文件承诺或专有格式不保证可恢复。
- ⌥⌘V 等其他组合键保持原有用途；若 ⌘⇧V 被占用，可改用菜单栏入口。
- 系统安全输入、目标应用的权限和辅助功能支持情况会影响全局按键及直接粘贴。
- 目前没有云同步、OCR 或内置自动更新。

## 开发与验证

应用使用 Swift Package Manager，无第三方包依赖。运行测试：

```bash
swift test --disable-sandbox
```

打开隔离演示模式：

```bash
./scripts/run.sh --demo
```

演示模式使用示例数据、独立临时存储和命名剪贴板，不读取真实剪贴板历史，也不启用全局快捷键。

1.3.0 已通过 **111 项 XCTest**，覆盖历史存储、剪贴板格式往返、搜索、图片皮肤、长短按路由、图片缩略图与方向、异步切换、预览操作和窗口定位。详细测试与构建结果见 [VALIDATION.md](VALIDATION.md)。验证环境为 macOS 15.7.4 / Apple Silicon / Swift 6.2。

**真实跨应用长按、候选窗口与粘贴交互尚未完成验收**：验证环境的电脑操作权限不足。单元测试通过不等于已验证这些系统交互；Intel Mac 也尚未验收。详细结果及人工验收清单见 [VALIDATION.md](VALIDATION.md)。

### 项目结构

```text
ClipboardShelf/
├── Package.swift
├── Sources/ClipboardShelf/
│   ├── ClipboardShelfApp.swift   # 应用入口、菜单栏、权限和生命周期
│   ├── ClipboardService.swift    # 系统剪贴板采集与恢复
│   ├── HistoryCore.swift         # 历史模型、容量策略与备份存储
│   ├── PasteTrigger.swift        # 全局按键监听与粘贴事件
│   ├── PasteHoldRouting.swift    # 短按 / 长按状态机
│   ├── CandidateController.swift # 候选窗口与目标应用交互
│   ├── CandidateModel.swift      # 候选选择、过滤与窗口定位
│   ├── CandidateView.swift       # 小候选框界面
│   ├── ClipboardImagePreview.swift # 后台图片解码与缩略图缓存
│   ├── ClipSearch.swift          # 搜索匹配
│   ├── AppearanceStorage.swift   # 本地背景图片处理与存储
│   ├── ShelfTheme.swift          # 主题及外观设置
│   ├── ShelfView.swift           # 历史管理界面
│   ├── AppModel.swift            # 应用状态与操作
│   └── GlobalShortcut.swift      # ⌘⇧V 备用快捷键
├── Tests/ClipboardShelfTests/
├── Resources/                   # Info.plist 与图标生成代码
├── scripts/                     # 构建和运行脚本
└── VALIDATION.md
```

测试使用临时目录与独立命名剪贴板，不读取或修改系统通用剪贴板。提交问题时，请附上应用版本、macOS 版本、复现步骤及「检查长按状态…」的文字状态；避免附带真实剪贴板内容或含敏感信息的备份。
